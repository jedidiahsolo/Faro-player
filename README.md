# Faro

A responsive music player built with React, TypeScript, and Vite. Browse the listening room, search the track list, pick songs from the queue, and control playback from the persistent player bar.

## Run locally

```sh
npm install
npm run dev
```

## Validate a production build

```sh
npm run build
```

Audio is streamed from public sample tracks; an internet connection is required for playback. Artwork is loaded from Unsplash.
